Active Grants

Valid sudo grants authorize one exact, shell-free command. Approval here only writes the database row; run goethe-perm sync-sudoers in a terminal to install valid grants. Unsafe legacy grants are marked not installable and ignored during sync; revoke and recreate them as exact commands.
The Console never writes /etc/sudoers.d/goethe-grants. The button only opens a terminal with the command ready; you confirm it and sudo still prompts for your password.
